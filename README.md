# 明·成长｜2604 成绩管理

适合初一的成绩记录与分析网站。直接双击 `index.html` 即可本地使用；GitHub Pages 也可托管同一文件。

## 使用

1. 新建考试，选择平时、期中或期末，按试卷设置各科满分。
2. 在“数据管理”添加学生，或在“成绩总表”下载 CSV 模板，填写后导入。
3. 查看班级概览、单科分析和学生成长档案；个人报告可打印。
4. 定期在“数据管理”下载 JSON 备份。换浏览器、设备或从本地文件切换到 GitHub Pages 时，在新页面恢复备份。

平时和期中为语文、数学、英语；期末另含道德与法治、历史、地理、生物。`0` 分计入统计，空白或缺考不计入。三科趋势按得分率计算，七科总分只在期末单独显示。

数据只保存在当前浏览器的 `localStorage`，不会上传到 GitHub 或自动跨设备同步。此仓库不含学生或成绩数据。请勿将 JSON 备份、CSV 成绩文件提交到仓库。

编辑 `app.js`、`style.css` 或 `emblem.png` 后，运行 `python3 build.py` 更新单文件 `index.html`。
