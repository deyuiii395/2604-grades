# 明·成长｜2604 成绩管理

适合初一的成绩记录与分析。`index.html` 是完整的单文件网站，可以直接在本地打开，也通过 GitHub Pages 发布。

## 使用

1. 打开“数据管理”，选择学号名册 Excel（`.xlsx`）或 CSV。网站会把“作业编号”或“学号”列作为学号、把“姓名”列作为姓名；无需逐个录入。名册只在当前浏览器处理和保存。
2. 新建考试，选择平时、期中或期末，按实际试卷设置满分。考试会按日期自动插入顺序；在“数据管理”可用箭头调整考试顺序。
3. 在“成绩总表”直接选择成绩 Excel（`.xlsx`）或 CSV。可识别常见的姓名、编号和科目列名；只有姓名时按已导入名册匹配。也可下载模板或手动编辑成绩。
4. 查看概览、学科分析和个人成长档案。个人报告包含三科得分率、班内名次、单科与班均差距、较上次变化、期末七科总分及有依据的复盘提示。
5. 定期下载 JSON 备份。换浏览器、设备或从本地文件切换到 GitHub Pages 时，用备份恢复。

平时/期中分析语文、数学、英语，期末另外显示道德与法治、历史、地理、生物。`0` 分计入统计，空白或缺考不计入。各科满分由实际试卷决定。

数据只保存在当前浏览器的 `localStorage`，不会上传到 GitHub 或自动跨设备同步。此仓库不含学生或成绩数据；请勿提交 JSON 备份、CSV 成绩文件或原始 Excel 名册。

编辑 `app.js`、`excel.js`、`style.css` 或 `emblem.png` 后运行 `python3 build.py` 更新单文件 `index.html`。Excel 解压使用随源代码一起提供的 MIT 许可 fflate，网页运行时无需联网加载依赖。

成长档案的“打印成长报告”使用独立 A4 黑白版式：成绩记录、学生反思与家长留言，含签名和日期。历次成绩每 8 场分组续页，反思与留言另起一页，书写横线无需开启背景图形即可打印。打印对话框建议关闭浏览器页眉和页脚。网页中的自动复盘建议不进入打印稿。

成长档案网页直接显示与打印一致的正式记录、学生反思和家长留言，趋势与学科分析可展开查看。正式成长记录目前仅展示语文、数学、英语三科，不展示小四门及七科总分；反思与留言用于打印后亲笔填写。

打印稿现包含三科成绩、历次记录、本次与班级比较、下一步复盘、学生反思与家长留言，均不显示名次。成长档案提供“打印当前学生”和“批量打印全班”按钮；批量使用当前所选考试与名册顺序，每位学生单独起页。网页不显示纸质稿全文，打印完成或取消后恢复单人打印状态。
