# 明·成长｜2604 成绩管理

适合初一的成绩记录与分析。`index.html` 是完整的单文件网站，可以直接在本地打开，也通过 GitHub Pages 发布。

## 使用

1. 打开“数据管理”，选择学号名册 Excel（`.xlsx`）或 CSV。网站会把“作业编号”或“学号”列作为学号、把“姓名”列作为姓名；无需逐个录入。名册只在当前浏览器处理和保存。
2. 新建考试，选择平时、期中或期末，按实际试卷设置满分。考试会按日期自动插入顺序；在“数据管理”可用箭头调整考试顺序，也可修改考试名称而不影响已有成绩。
3. 在“成绩总表”直接选择成绩 Excel（`.xlsx`）或 CSV。可识别常见的姓名、编号和科目列名；只有姓名时按已导入名册匹配。也可下载模板或手动编辑成绩。
4. 查看概览、学科分析和个人成长档案。语文、数学、英语三个模块横向排列，正态参考图与 20 分区间明细表同时显示；窄屏可横向滚动。学科分析还展示平均分、及格率、优秀率、进步人数与进步之星；另有三科总成绩进步之星。两次期末成绩可比时，也展示七科总成绩进步之星。
5. 定期下载 JSON 备份。换浏览器、设备或从本地文件切换到 GitHub Pages 时，用备份恢复。

平时/期中分析语文、数学、英语，期末另外显示道德与法治、历史、地理、生物。`0` 分计入统计，空白或缺考不计入。各科满分由实际试卷决定。

进步比较使用按试卷满分换算的得分率，只纳入前后两次对应科目成绩齐全的学生；每个科目与总成绩各选最多 10 位提升幅度大于零的进步之星。提升幅度相同时，先选上次得分率较低者，再按学号确定顺序。三科总成绩始终比较语数外，七科总成绩仅比较两次期末考试。进步之星是本次变化提示，不显示考试名次。

成绩分布以原始分数每 20 分一档，末档包含该科满分。图中柱子是实际人数，曲线是正态参考；图下的明细表直接显示各档人数和占比。有效成绩至少 10 份且标准差大于 0 时，才显示按本次均分与标准差拟合、限制在 0 至满分范围内的正态参考。曲线和参考人数是模型估计，不表示真实成绩服从正态分布。

数据只保存在当前浏览器的 `localStorage`，不会上传到 GitHub 或自动跨设备同步。此仓库不含学生或成绩数据；请勿提交 JSON 备份、CSV 成绩文件或原始 Excel 名册。

编辑 `app.js`、`excel.js`、`style.css` 或 `emblem.png` 后运行 `python3 build.py` 更新单文件 `index.html`。Excel 解压使用随源代码一起提供的 MIT 许可 fflate，网页运行时无需联网加载依赖。

成长档案的“打印成长报告”使用独立 A4 黑白版式：成绩记录、学生反思与家长留言，含签名和日期。历次成绩每 8 场分组续页，反思与留言另起一页，书写横线无需开启背景图形即可打印。打印对话框建议关闭浏览器页眉和页脚。网页中的自动复盘建议不进入打印稿。

成长档案网页直接显示与打印一致的正式记录、学生反思和家长留言，趋势与学科分析可展开查看。正式成长记录目前仅展示语文、数学、英语三科，不展示小四门及七科总分；反思与留言用于打印后亲笔填写。

打印稿现包含三科成绩、历次记录、本次与班级比较、下一步复盘、学生反思与家长留言，均不显示名次。成长档案提供“打印当前学生”和“批量打印全班”按钮；批量使用当前所选考试与名册顺序，每位学生单独起页。网页不显示纸质稿全文，打印完成或取消后恢复单人打印状态。

最新打印版采用成长信与回信形式，正文嵌入三科个人成绩表和历次记录，保留个人复盘、学生反思及家长留言。成长档案与打印信不含排名、班均分或班均比较；上述旧版“本次与班级比较”已被个人复盘替代。

## 作业记录

“作业记录”按学生、学科和每次作业保存状态，自动计算优秀、缺交、待核次数。点击学生可查看缺交发生的日期、同日第几次登记、作业内容、统计标记和来源文件页码。点击“修改”可更正单条状态与备注；也可新增或编辑作业项目。状态“未登记”与“待核”均不自动算作缺交。

已核对的四科逐次记录放在本机 `outputs/2026-11-06_作业网站导入/2604作业逐次记录.json`，**不提交到此公开仓库**。首次使用时在网页“作业记录”点击“导入逐次记录 JSON”，选择该文件并确认；若已有成绩，导入仅新增或更新作业记录，考试和成绩保留。四科来源分别为十月数学 16 次、十月历史 3 次、十月语文 16 次、本学期道德与法治 14 次，共 49 个作业项目。逐次状态与原统计表汇总对齐。

浏览器内的在线修改只保存在当前浏览器。完整 JSON 备份同时包含考试成绩与作业记录；换设备或浏览器时需下载备份并在目标浏览器恢复。网页没有服务器数据库，也不会自动同步。请勿将上述逐次记录 JSON、完整备份或学生名单提交到 GitHub。
